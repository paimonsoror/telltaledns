Helm values

Every option of the Kubernetes chart, generated from the chart's own values.yaml and its comments, so it can't drift from the chart.

  • The whole file, with its comments, for the version you install: 
    helm show values oci://ghcr.io/paimonsoror/charts/telltale > values.yaml
# or one version: --version X.Y.Z (builds from main: --devel, or --version X.Y.Z-edge.N)
  • The file on GitHub: deploy/helm/telltale/values.yaml.
  • Keep only what you change in your own file and install with -f my-values.yaml. The chart checks values against its schema, so a mistyped value fails the install with the key's path.
  • TelltaleDNS's own settings go in config: as TOML; every key is in the configuration reference.
