DNS in one picture

DNS is your network's phone book. Because every connection starts with a lookup, the DNS server is the one place that can see — and decide — what your devices talk to.

  • Block ads and trackers for every device, even smart TVs.
  • Encrypt lookups so your ISP can't read them.
  • Spot the gadget that phones home at 3 a.m.

Quick start

Three steps

Preview: build from source today. One-command installs arrive with the deployment milestone.

Install

From source (works today)

git clone https://github.com/paimonsoror/telltaledns
cd telltaledns
cargo build --release
./target/release/telltale --version

Docker (preview: edge, built from main)

docker run -d --name telltale --read-only --cap-drop ALL \
  -p 53:53/udp -p 53:53/tcp -p 9153:9153 \
  -v "$PWD/telltale.toml:/etc/telltale/telltale.toml:ro" \
  -v telltale-data:/var/lib/telltale \
  ghcr.io/paimonsoror/telltale:edge

amd64, arm64 and arm/v7; about 3 MiB; runs as a non-root user.

Raspberry Pi (coming soon)

# planned (roadmap M4): same image, Docker Compose
docker compose up -d

Kubernetes (Helm, one replica)

git clone https://github.com/paimonsoror/telltaledns
helm install telltale telltaledns/deploy/helm/telltale -n telltale --create-namespace
kubectl -n telltale get svc telltale-dns   # EXTERNAL-IP: hand this out in DHCP

One LoadBalancer for UDP and TCP 53 with externalTrafficPolicy: Local, so every device shows up with its own address. If something hides them anyway (a node, a Docker bridge, a router forwarding DNS), the UI says "client IPs appear masked" and links to the fix.

Configure

Save as telltale.toml. This uses encrypted upstreams.

[[upstream]]
name = "cloudflare"
url = "tls://1.1.1.1"
tls_server_name = "cloudflare-dns.com"

[[upstream]]
name = "quad9"
url = "https://dns.quad9.net/dns-query"
bootstrap = ["9.9.9.9"]

[[upstream_group]]
name = "default"
members = ["cloudflare", "quad9"]
strategy = "fastest"

Run and test

sudo ./target/release/telltale run -c telltale.toml
dig @127.0.0.1 example.com

Then point your router's DHCP "DNS server" setting at this machine so every device uses it.

Make it network-wide

Most routers have a DNS server field under DHCP or LAN settings. Put TelltaleDNS's address there (and a second instance's, once clustering lands, for redundancy).
