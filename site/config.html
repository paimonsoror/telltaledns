Configuration

Every setting in telltale.toml, generated from the same schema the binary validates against, so it can't drift from the code.

  • Every key is optional: anything you leave out uses the default shown here.
  • [name] is a table (set once); [[name]] is a list of tables (repeat it for each entry).
  • Check a file before using it: telltale config check telltale.toml. Unknown keys are errors, with the path to the mistake.
  • Editor completion: telltale config schema > telltale.schema.json and point your TOML extension at it.
  • Environment variables override the file: TELLTALE_CACHE_MAX_TTL=3600 sets [cache] max_ttl.
  • Changes apply on reload (SIGHUP) without dropping queries, except [node], [cache], [telemetry], and [filter], which need a restart.
